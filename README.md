# WFA Amadeus Practice Simulator

Wings Fly Aviation Academy-এর নিজস্ব Amadeus প্র্যাকটিস সিমুলেটর — ল্যাবের ১৫টা PC-তে আলাদা Amadeus ID না কিনেও স্টুডেন্টরা প্র্যাকটিস করতে পারবে। ডেস্কটপ ও মোবাইল (Android/iOS ব্রাউজার) দুটোতেই কাজ করে।

**এটা একটা স্বাধীন এডুকেশনাল টুল — Amadeus IT Group-এর সাথে কোনো অ্যাফিলিয়েশন বা এন্ডোর্সমেন্ট নেই। কোনো লাইভ GDS-এর সাথে কানেক্টেড না।**

## ফাইল
- `index.html` — পুরো অ্যাপ (একটাই ফাইল, আলাদা সার্ভার/ব্যাকএন্ড লাগবে না)
- `COMMANDS_CHEATSHEET.md` — প্র্যাকটিসের জন্য কপি-পেস্ট কমান্ড লিস্ট

## GitHub Pages দিয়ে ফ্রি পাবলিশ করা

1. [github.com](https://github.com)-এ একটা নতুন রিপোজিটরি বানান (যেমন `amadeus-simulator`)
2. এই ফোল্ডারের `index.html` ফাইলটা রিপোজিটরিতে আপলোড করুন (GitHub-এর "Add file → Upload files" বাটন দিয়ে, কোনো কমান্ড লাইন লাগবে না)
3. রিপোজিটরির **Settings → Pages**-এ যান
4. "Source" থেকে **Deploy from a branch** বেছে নিন, branch = `main`, folder = `/ (root)`, তারপর **Save**
5. কিছুক্ষণ পর একটা লিংক পাবেন — সাধারণত এই ফরম্যাটে:
   `https://[আপনার-গিটহাব-ইউজারনেম].github.io/amadeus-simulator/`
6. এই লিংক স্টুডেন্টদের শেয়ার করুন — ডেস্কটপ বা মোবাইল ব্রাউজারে খুললেই কাজ করবে

## Vercel দিয়ে পাবলিশ করা (বিকল্প)

1. [vercel.com](https://vercel.com)-এ ফ্রি অ্যাকাউন্ট বানান (GitHub দিয়ে সাইন-আপ করলে সবচেয়ে সহজ)
2. "Add New → Project" থেকে আপনার GitHub রিপোজিটরিটা সিলেক্ট করুন
3. কোনো সেটিংস বদলানোর দরকার নেই (এটা প্লেইন HTML, তাই Vercel নিজে থেকেই ঠিকভাবে ডিপ্লয় করবে) — **Deploy** চাপুন
4. কিছু সেকেন্ডের মধ্যে একটা লিংক পাবেন (যেমন `amadeus-simulator.vercel.app`)

## আপডেট করতে হলে

ভবিষ্যতে নতুন কমান্ড বা রুট যোগ করতে চাইলে `index.html` ফাইলটা এডিট করে আবার আপলোড করলেই (GitHub-এ) বা রিপোজিটরিতে push করলেই (Vercel) সাইট নিজে থেকে আপডেট হয়ে যাবে।
